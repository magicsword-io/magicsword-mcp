# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not open a public issue for a suspected vulnerability or include API keys,
customer data, or exploit details in public discussions.

If private vulnerability reporting is unavailable, contact the MagicSword
team through the support channel listed at [magicsword.io](https://magicsword.io).

## Supported versions

Security fixes are provided for the latest published version. Upgrade to the
latest release before reporting an issue that may already be resolved.
